SQL Server Agent Runbooks

Reference guide for responding to SQL Server Agent alerts and SQL monitoring job notifications across production environments. Click any entry to expand its runbook. Use the tabs to navigate between overview, SQL queries, and follow-up steps.

For WARNING Alerts: Focus on identifying patterns rather than reacting immediately. Perform initial checks, then monitor behavior over time—many alerts are benign one-offs (ex. Disk Latency). If alerts continue, evaluate whether the monitoring thresholds need adjustment or further investigative action needs to be taken.

An additional note: alerts that occur during scheduled maintenance windows (commonly overnight, e.g., 12am–3am) may be expected depending on workload activity.
